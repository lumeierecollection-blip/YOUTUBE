# Claude Code print mode

Provisional, hand-planned.

- hook: Claude Code can answer once, then exit. No chat. [c1]
- reference: The CLI reference: dash p prints the response without interactive mode. [c2]
- terminal: Run help. The print and output-format flags appear in the real output. [c3]
- pipe: Pipe a log file in, ask a question, and get the answer back. [c4]
- controls: Output format takes text, json or stream-json. Max turns caps agentic turns. [c5,c6]
- close: A chat-free mode, one flag away. [c2]
