## Narration as spoken

How does sleep actually process our memories? Memory comes from brain plasticity, structural changes within synapses that connect stimuli. Nocturnal sleep and daytime naps stabilize and enhance these memory processes. Hippocampus activity, the seahorse-shaped structure for memory, directly causes plastic changes and better performance. Sleep actively reorganizes brain connections to lock in memories.
