# Thumbnail Maker Skill

## Purpose
Produce a thumbnail that reflects the actual hook/claim of the finished
script — not a generic template image.

## Process
1. Pull the confirmed hook/core claim from the finished script.
2. Generate or compose a thumbnail: bold short text (3-6 words max,
   readable at small size) + a supporting visual tied to the actual topic.
3. Match the channel's established visual style (colors/fonts) if one
   exists in the channel config; otherwise establish one on first run and
   record it in the config for consistency across future videos.
4. Output at YouTube's recommended thumbnail spec (1280x720, under 2MB).

## Rules
- Text on the thumbnail must be an accurate reflection of the video's
  actual content — no clickbait that isn't backed by the script.
- Keep a consistent style per channel over time so the channel is visually
  recognizable.
