# Deep Research Skill

## Purpose
Every topic must be backed by real, current, multi-source research before
any script is written. This skill never invents facts and never writes the
final script — it gathers and summarizes, then hands off for human
clarification.

## Process (minimum 3-4 distinct search passes per topic)

1. **Pass 1 — broad web pass.** General search on the topic/niche to
   understand the current landscape and any recent news.
2. **Pass 2 — narrow/factual pass.** Re-search with more specific terms
   surfaced from pass 1 (names, numbers, events) to verify and deepen facts.
3. **Pass 3 — practitioner pass.** Search specifically for what other
   people already running YouTube channels or automation in this niche are
   doing/recommending — creator forums, YouTube-automation communities,
   niche-specific "how I grew this channel" posts.
4. **Pass 4 — social/community pass.** Search Reddit, X/Twitter, or niche
   forums for what people are actually discussing about this topic right
   now — this is where a genuine "why would a stranger care" hook usually
   comes from.

Each pass should use different search terms than the last — don't repeat
the same query. If a pass turns up a contradiction or gap, run an extra
pass to resolve it before moving on.

## Output format (every time)
Return to the user:
- **Topic**
- **Key facts found** (each tagged with its source)
- **Strongest angle/hook** based on what's actually trending or discussed
- **What practitioners in this niche are doing** (if relevant)
- **Open questions or gaps** — call these out explicitly rather than
  filling them in

Do not proceed to script-writing until the user replies with edits or
confirmation.

## Rules
- Never state a fact that wasn't found in an actual search result this
  session.
- Never combine research passes into a single generic search — the whole
  point is different angles catching different things.
- If sources conflict, say so; don't silently pick one.
