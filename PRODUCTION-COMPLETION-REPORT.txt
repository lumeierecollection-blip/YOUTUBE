--------------------------------------------------------------------------------
2.1 scripts/visual-beat-grouper.js (~7KB)
--------------------------------------------------------------------------------
Purpose: Deterministic SRT subtitle to visual beat grouping

What it does:
  - Parses SRT files into timed cues
  - Groups consecutive cues into coherent visual beats based on:
    * Pause detection (configurable threshold, default 0.35s)
    * Sentence boundary detection (periods, exclamation, question marks)
    * Clause boundary detection (commas, semicolons, dashes)
    * Minimum/maximum beat duration (style-dependent)
  - Merges short beats that are semantically continuous
  - Splits long beats at natural break points
  - Preserves all original cue timing data

Exports:
  - groupCuesIntoBeats(cues, options) -> beats[]
  - parseSrt(srtText) -> cues[]
  - wordCount(text) -> number

Style-aware timing:
  - cinematic-documentary: min 4.0s, max 8.0s, pause 0.4s
  - motion-graphics:       min 2.5s, max 6.0s, pause 0.25s
  - minimal:               min 3.0s, max 7.0s, pause 0.35s

CLI usage:
  node scripts/visual-beat-grouper.js --srt FILE [--channel ID] [--out FILE]

--------------------------------------------------------------------------------
2.2 scripts/local-audit.js (~11KB)
--------------------------------------------------------------------------------
Purpose: Deterministic local video auditing — zero Gemini tokens

What it checks (7 checks):
  1. Resolution:     Must be 1080x1920 (vertical Shorts format)
  2. FPS:            Must be ~30fps
  3. Duration:       Must be 15-720 seconds
  4. Black frames:   Detects sustained black segments (>2s = FAIL)
  5. Scene changes:  Visual event density (warns if <0.1/sec)
  6. Audio loudness: Measures LUFS via FFmpeg loudnorm filter
  7. File size:      Must be 0.1-500 MB

Risk levels:
  - NORMAL:  0 failures, <3 warnings -> Skip Gemini review
  - MEDIUM:  1+ failures OR 3+ warnings -> Run batched Gemini review
  - HIGH:    3+ failures -> Run targeted Gemini review

Dependencies:
  - ffprobe (Remotion compositor bundled or system PATH)
  - ffmpeg (for audio loudness measurement)

CLI usage:
  node scripts/local-audit.js --video PATH --channel ID [--plan PATH] [--out PATH]

Output:
  - JSON report at data/audit/local-audit/{channel}-{video}-audit.json
  - Console summary with risk level and check results

--------------------------------------------------------------------------------
2.3 scripts/risk-based-review.js (~6KB)
--------------------------------------------------------------------------------
Purpose: Orchestrates risk-based post-render Gemini review

Flow:
  1. Run local deterministic auditor FIRST
  2. If NORMAL risk -> 0 Gemini calls -> APPROVED
  3. If MEDIUM risk -> one batched Gemini review
  4. If HIGH risk -> targeted Gemini reviews
  5. Corrections are DELTAS, not full plan regenerations

CLI usage:
  node scripts/risk-based-review.js --video PATH --channel ID [--plan PATH]

Output:
  - JSON review report at data/audit/local-audit/{channel}-{video}-review.json
  - Verdict: APPROVED, NEEDS_CORRECTION, or REJECTED

--------------------------------------------------------------------------------
2.4 scripts/plan-cache.js (~4KB)
--------------------------------------------------------------------------------
Purpose: Content-hash-based visual plan caching

How it works:
  - Hashes: script content + SRT content + channel config (style, colors,
    font, bg_mode, asset_treatment) + capability version + schema version
  - Algorithm: SHA-256
  - Cache location: .cache/visual-plans/{hash}.json
  - TTL: 30 days
  - On cache hit: skips Gemini API call entirely

Exports:
  - planCacheKey(scriptPath, srtPath, channelId, channelConfig) -> hash
  - getCachedPlan(cacheKey) -> plan | null
  - setCachedPlan(cacheKey, plan) -> void
  - invalidatePlan(cacheKey) -> void
  - getCacheStats() -> { entries: number }

CLI usage:
  node scripts/plan-cache.js --stats

--------------------------------------------------------------------------------
2.5 scripts/gemini-visual-plan-enhanced.js (~4KB)
--------------------------------------------------------------------------------
Purpose: Drop-in replacement for gemini-visual-plan.js with enhancements

Adds to original planner:
  1. Visual beat grouping (SRT cues -> coherent beats before Gemini call)
  2. Plan caching (content-hash based, avoids regenerating same plans)
  3. Token savings reporting

Flow:
  1. Check plan cache -> if HIT, return cached plan
  2. Group SRT cues into beats (reports savings)
  3. Delegate to original gemini-visual-plan.js
  4. Cache the generated plan
  5. Report token savings

CLI usage:
  node scripts/gemini-visual-plan-enhanced.js --script PATH --srt PATH --channel ID --out PATH

--------------------------------------------------------------------------------
2.6 scripts/render-and-qa-enhanced.js (~10KB)
--------------------------------------------------------------------------------
Purpose: Drop-in replacement for render-and-qa.js with all enhancements

Enhancements over original:
  1. Uses gemini-visual-plan-enhanced.js (beat grouping + caching)
  2. Runs local-audit.js AFTER render (deterministic, no tokens)
  3. Risk-based Gemini review (skips for NORMAL risk)
  4. Reports local audit risk level in results

Flow per video:
  1. Gemini Visual Plan (enhanced: beat grouping + cache)
  2. Render with Remotion
  3. Local deterministic audit (zero tokens)
  4. Risk-based decision:
     - NORMAL -> skip Gemini review (saves tokens)
     - MEDIUM/HIGH -> run Gemini review
  5. If not approved -> correction loop (max 3 attempts)

CLI usage:
  node scripts/render-and-qa-enhanced.js [--channel ID] [--script PATH] [--dry-run]

--------------------------------------------------------------------------------
3.1 local-audit.js: require() in ESM context
--------------------------------------------------------------------------------
Problem:  Line 260 used require('node:fs').statSync(videoPath) in ESM module
Fix:      Changed to dynamic import: const { statSync } = await import('node:fs')

--------------------------------------------------------------------------------
3.2 local-audit.js: Missing codec_type in ffprobe output
--------------------------------------------------------------------------------
Problem:  ffprobe called without codec_type, so find(s => s.codec_type === 'video')
          returned undefined, causing 0x0 resolution and 0.0 fps
Fix:      Added codec_type to ffprobe -show_entries stream list

--------------------------------------------------------------------------------
3.3 local-audit.js: Incorrect ffprobe -show_entries format
--------------------------------------------------------------------------------
Problem:  Used single -show_entries with colon separator which some ffprobe
          versions do not support
Fix:      Split into separate -show_entries for format and stream

--------------------------------------------------------------------------------
3.4 visual-beat-grouper.js: main() runs on import
--------------------------------------------------------------------------------
Problem:  Bare main(); at module bottom executed when file was imported
Fix:      Guarded with process.argv check so it only runs when executed directly

================================================================================

Before (old architecture):
  SRT -> individual cues -> Gemini (per cue) -> render -> Gemini review -> loop
  Cost: 2-3 Gemini calls per video minimum

After (new architecture):

  SRT cues
     |
     v
  [Beat Grouper] -----> Grouped Beats
                             |
                             v
                     [Plan Cache Check]
                          |       |
                     HIT  |       | MISS
                          v       v
                     Reuse    Gemini Plan
                     cached   (enhanced)
                          |       |
                          v       v
                     [Remotion Render]
                             |
                             v
                 [Local Deterministic Audit]
                             |
                 +-----------+-----------+
                 v           v           v
              NORMAL      MEDIUM       HIGH
                 |           |           |
                 v           v           v
              DONE      Gemini      Gemini
           (0 tokens)  1 batched   targeted
                             |           |
                             v           v
