# SFX Source Log — Verified Free/Open Sound Effect Sources

All sources verified for license type and commercial YouTube use eligibility.

---

## GitHub Repositories

### 1. Kenney Audio Packs (CC0)
- **URL**: https://kenney.nl/assets?q=audio
- **License**: CC0 / Public Domain
- **Commercial YouTube**: YES — no restrictions
- **Categories**: Interface sounds, impacts, transitions, ambient, UI clicks
- **Files**: 1000+ across multiple packs
- **Notes**: Used by Cy4nWare/sfx-api. Highest quality CC0 game audio.

### 2. lavenderdotpet/CC0-Public-Domain-Sounds
- **URL**: https://github.com/lavenderdotpet/CC0-Public-Domain-Sounds
- **License**: CC0-1.0
- **Commercial YouTube**: YES — no restrictions
- **Categories**: SFX, wood/metal, bangs, mud, loops, weird, water/splash, retro synth, sci-fi, RPG, creature sounds
- **Files**: 500+ across 20+ packs
- **Stars**: 44

### 3. Cy4nWare/sfx-api
- **URL**: https://github.com/Cy4nWare/sfx-api
- **License**: CC0 (Kenney sounds only)
- **Commercial YouTube**: YES — no restrictions
- **Categories**: UI sounds, interface clicks, transitions
- **Setup**: npm run build to index, jsDelivr CDN for hosting
- **Notes**: API-style access to CC0 sounds via GitHub + jsDelivr

### 4. arnofaure/free-sfx
- **URL**: https://github.com/arnofaure/free-sfx
- **License**: CC BY 4.0 (attribution required, no selling the pack)
- **Commercial YouTube**: YES — with attribution
- **Categories**: Alert, input, music, sci-fi, voice, woosh (36 sounds)
- **Formats**: AIFF, MP3, OGG
- **Notes**: Small but curated. Woosh sounds especially useful.

### 5. itch.io CC0 SFX Packs
- **URL**: https://itch.io/game-assets/assets-cc0/tag-sound-effects
- **License**: CC0 (per pack — verify each)
- **Commercial YouTube**: YES — check individual pack licenses
- **Categories**: Horror, interface, RPG, ambient, UI
- **Notable packs**: "200 Free SFX", "Interface SFX Pack 1", "ROT: Horror Audio Bundle"

## Free SFX Websites

### 6. Freesound.org
- **URL**: https://freesound.org/
- **License**: Mixed — filter by CC0 tag
- **Commercial YouTube**: YES for CC0 files — check each sound
- **Categories**: 500K+ sounds — everything
- **Filter**: Use tag "CC0" to find public domain sounds
- **Notes**: Largest free SFX library. Requires account for downloads.

### 7. Mixkit
- **URL**: https://mixkit.co/free-sound-effects/
- **License**: Free license (no attribution required)
- **Commercial YouTube**: YES
- **Categories**: Transitions, whooshes, impacts, ambient, UI
- **Notes**: Curated, high quality. Quick download, no account needed.

### 8. ZapSplat
- **URL**: https://www.zapsplat.com/
- **License**: Free tier (attribution may be required)
- **Commercial YouTube**: YES with attribution
- **Categories**: UI, cartoon, cinematic hits, whooshes, transitions
- **Notes**: 160K+ SFX. YouTube-specific sound pack available.

### 9. Pixabay Sound Effects
- **URL**: https://pixabay.com/sound-effects/
- **License**: Pixabay Content License
- **Commercial YouTube**: YES
- **Categories**: Ambience, stingers, transitions, UI
- **Notes**: Community uploads. Verify terms on license page.

### 10. YouTube Audio Library
- **URL**: https://studio.youtube.com/channel/UC/music
- **License**: YouTube-specific (Content ID safe)
- **Commercial YouTube**: YES — built for YouTube creators
- **Categories**: Music + some SFX
- **Notes**: Safest option for YouTube. Built into Studio.

### 11. UnstuntedSFX
- **URL**: https://unstuntedsfx.net/
- **License**: CC0
- **Commercial YouTube**: YES — no attribution
- **Categories**: 250,000+ SFX, hum-to-search AI, Premiere/DaVinci plugins
- **Notes**: Large library with AI search. No attribution required.

### 12. Sonniss Game Audio GDC Bundles
- **URL**: https://sonniss.com/gameaudiogdc
- **License**: Royalty-free (check yearly terms)
- **Commercial YouTube**: YES
- **Categories**: Whooshes, impacts, design layers, cinematic
- **Notes**: High production value. Annual free bundles from GDC.
