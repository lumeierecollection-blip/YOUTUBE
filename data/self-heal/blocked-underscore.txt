Phase 5: underscore.mp3 fetcher (src/skills/music-sourcing/fetch-underscore.mjs) requires Playwright, which is not installed in the CI workflow. The render works without it (hasUnderscore=false). To enable: add 'npm install playwright' and 'npx playwright install chromium' to the render job, then add a step before 'Render + QA' that runs 'node src/skills/music-sourcing/fetch-underscore.mjs'. This is a nice-to-have, not a blocker for the pipeline.
