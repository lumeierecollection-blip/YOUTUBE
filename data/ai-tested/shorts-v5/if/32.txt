Anthropic just launched Claude Ship, in beta. It reviews pull requests, fixes them, and decides what is ready to merge. It has three parts. Code Review. PR Steward. And Claude Approvals. Code Review posts its findings on the pull request. PR Steward works on failing checks and merge conflicts, but it is designed not to approve or merge. Claude Approvals follows a policy file your team writes in the repository. Developers can run slash ship in Claude Code. It is on Team and Enterprise plans, for GitHub repositories.
