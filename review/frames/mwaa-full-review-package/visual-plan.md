## Beat-by-Beat Visual Plan

### Beat 1 — Hook (0–4s)
**Narration:** "Amazon Managed Workflows for Apache Airflow now includes four specific AI skills for AWS."  
**Visual Treatment:** article-highlights  
- Editorial paper card on charcoal surface

  - `◇ skill added: remotion-frame-guard ✓`
  - `◇ skill added: export-reviewer`

### Beat 3 — Rehook (15–20s)
**Narration:** "Amazon MWAA enables upgrading environments using any AI coding assistant, but the toolkit also includes authoring-mwaa-workflow and debugging-mwaa-workflow."  
**Visual Treatment:** cinematic-camera  
- Single connected world larger than viewport

- Opens tight on terminal command completing

- Reveals connected MWAA environment (servers, DAG nodes, worker fleets)
- Travels to the upgrade skill as payoff
- Settles for clean editor hold
- **One primary action per beat; camera guides causality**

### Beat 4 — Payoff (20–31s)
**Narration:** "Amazon Managed Workflows for Apache Airflow includes authoring-mwaa-workflow and debugging-mwaa-workflow skills."

- Real skill names only — no invented metrics or claims
- Camera: micro-motion only (typing, ticking, checking)
- **No generic dashboard or floating cards**

### Beat 5 — Close (31–35s)
**Narration:** "Use upgrading-mwaa-environments in Amazon Managed Workflows for Apache Airflow."

- End with clean editor hold

## Visual Identity Rules (per skill mandates)

**Absolute bans (never violate):**
- Zero neon, glow, bloom, luminous edges, colored shadows
- Zero gradient orbs, radial color washes, cyan-purple gradients
- Zero glassmorphism, cyberpunk lighting, vibe-coded AI styling
- No generic receipt, invoice, dossier, clipboard, barcode, rubber stamp
- No fake dashboard, disconnected card-grid, or invented UI
- No redundant narration text as large decorative text

**Required techniques:**
- Motion driven by `useCurrentFrame()`, `spring()`, `interpolate()` — no CSS animation
- Hold → travel → hold when travel helps; action completes during holds
- End with stable editor hold
- Tabular numerals for any ticking data
- One primary action per beat

**Color palette (channel + skill compliant):**
- Surface: charcoal `#15181B` (clean dark, not black)
- Terminal: `#101214` / `#15181B`, neutral borders, neutral shadows
- Accent: `#8B5CF6` (channel purple, flat only — no glow)
- Text: warm white and muted gray
- Marker: muted yellow (semi-transparent, behind text)
