## Composition

One connected world larger than the viewport (2.5x width). Opens tight on terminal command already in progress, holds while action completes, then pulls back to reveal the connected MWAA environment (servers, DAG nodes, worker fleets) as the larger system. Four skill tiles appear in staggered sequence, each a distinct step in the pipeline; travel bridges them. Camera is restrained — authentic UI and causality carry the story, not decorative movement.

## Camera

Single shared keyframe timeline for focal point and zoom using interpolate() with inOut(Easing.cubic) easing. Camera moves to the next action; action completes during the hold. Opens tight (focal on terminal), holds while install command types and `LOADED` appears, pulls back to reveal environment, travels to skill tiles, settles for clean editor hold. Camera moves usually take 14-24 frames; end with two nearly identical keys for stable hold.

## Identity

Charcoal surface `#15181B` (clean dark, flat, no neon). Terminal: `#101214` / `#15181B`, 1px neutral border, neutral shadow, monospace typography (SF Mono / JetBrains Mono), warm white text, muted gray secondary, one restrained flat accent `#8B5CF6` (channel purple, flat only). AWS brand flat, no glow. Command prompt `~ $ `, `◇` prefix for install rows, `✓` for completion. Real skill names only: authoring-mwaa-workflow, debugging-mwaa-workflow, testing-mwaa-workflow, upgrading-mwaa-environments.

## Research match

Uses the openmontage-claude-pipeline mechanism: one connected pipeline, camera follows causality from input (skill install via `/plugin install aws-data-analytics@claude-plugins-official`) through work (CLI demonstration) into output (environment upgraded with `upgrading-mwaa-environments`). Each destination is a distinct step; travel bridges them. Research sources: AWS What's New Oct 15 2026 and MWAA User Guide — all skill names, capabilities, and installation commands verified against these sources.

## Anti-pattern

No neon, glow, bloom, cyan-purple gradients, glassmorphism, or cyberpunk lighting. No generic receipt, invoice, dossier, clipboard, floating card, barcode, rubber stamp, or fake dashboard. No disconnected card grid. No slow zoom as the only camera idea. No empty travel before action. No redundant narration text as large decorative text. No invented metrics, claims, controls, or product states. Static centered object with rows appearing plus slow zoom is not cinematic execution.
