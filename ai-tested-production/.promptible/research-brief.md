## Product or concept

Amazon Managed Workflows for Apache Airflow (MWAA) — a managed service for Apache Airflow that lets users set up and run data pipelines in the cloud at scale. AWS announced on Oct 15, 2026 that MWAA now integrates with the Agent Toolkit for AWS to provide four built-in AI agent skills: authoring-mwaa-workflow, debugging-mwaa-workflow, testing-mwaa-workflow, and upgrading-mwaa-environments. These skills let an AI coding assistant author, debug, test, and upgrade MWAA workflows using natural language.

## Authoritative sources

- https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-mwaa-ai-agent-skills (AWS What's New, Oct 15 2026 — primary announcement)
- https://docs.aws.amazon.com/mwaa/latest/userguide/using-agent-skills.html (MWAA User Guide — skill definitions, installation, example prompts)

## Real visual language

- Terminal/CLI surface: charcoal `#101214` / `#15181B`, 1px neutral border, neutral shadow, monospace typography (SF Mono / JetBrains Mono), warm white and muted gray text, one restrained flat accent
- Command prompt starts with `~ $ `, commands type character-by-character, `◇` prefixes install rows, `✓` marks completion
- AWS brand: flat, restrained, no neon or glow; channel accent `#8B5CF6` used flat only
- Editor/product UI is the world, not decorative cards; camera follows the exact action/state change

## Closest approved mechanism

`openmontage-claude-pipeline` — one connected pipeline, camera follows causality from input (skill install) through work (CLI demonstration) into output (environment upgraded). Camera follows causality from input through work into output. Each destination is a distinct step; travel bridges them.

## Motion plan

- Open tight on terminal command typing, hold while it completes
- Reveal connected MWAA environment (servers, DAG nodes, workers)
- Travel to four skill tiles in staggered sequence
- End with upgrading-mwaa-environments command + success state `✓ environment ready`
- Stable editor hold, no decorative motion

## Avoid

- Neon, glow, bloom, cyan-purple gradients, glassmorphism, cyberpunk styling
- Generic receipt, invoice, dossier, clipboard, floating card, barcode, rubber stamp
- Fake dashboard, disconnected card-grid, invented UI or metrics
- Redundant narration text as large decorative text
- Slow zoom as the only camera idea; empty travel before action
