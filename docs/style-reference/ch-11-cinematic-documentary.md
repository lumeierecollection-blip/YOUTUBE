# Style reference — Cosmic Frontiers (ch-11, cinematic-documentary)

**This is a derivation record, not a research report.** ch-01, ch-02 and
ch-09 have documents of the other kind: fields traced to real external
references that were fetched and cited. This channel's specification was
derived from the curated `visual_spec` block already in
`config/channels.json`, and every row below names the text it came from.
Treat it as sound provenance for a first render and as a candidate for
replacement by real reference research.

Generated by `scripts/build-visual-identity.js` from
`config/visual-identity.source.json` + `config/channels.json`.
