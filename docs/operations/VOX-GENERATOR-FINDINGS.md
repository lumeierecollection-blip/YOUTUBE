## What it is

A thin Python orchestration layer (about 2,000 lines) over a paid cloud service, **MuAPI** (`api.muapi.ai`). Its own code does very little itself:

| Stage | Script | What actually does the work |
|---|---|---|
| Beats / script | `beats.json` written by the agent | The coding agent (Claude Code or similar) |
| Style choice | `style_bakeoff.py`, `styles.py` | Prompt text for "paper-collage" looks |
| Collage posters | `keyframes.py`, `croll_keyframes.py` | MuAPI image models (`flux-dev`, imagen, nano-banana) generate each poster from a prompt |
| Photo anchoring (C-roll) | `croll_keyframes.py` | MuAPI `remove-background`, then an image **edit** model re-draws a poster around the subject |
| Motion | `clips.py` | MuAPI `veo3.1-image-to-video` (8 s clips) |
| Voice and music | `audio.py` | MuAPI TTS and `suno-create-music` |
| Assembly | `assemble.py`, `text_overlay.py` | Local ffmpeg: concat, ducking, captions, watermark |
| Talking-head mode | `asr_beats.py`, `aroll_*.py` | MuAPI ASR and video restyle |

Required: `MUAPI_API_KEY`, ffmpeg, Python 3 with Pillow. Pricing is not stated in the README and the MuAPI price page was not fetched: **cost not determined**.

## Why the generator itself is the wrong tool for Court & Spotlight, even with a licence

1. **It makes AI images of the people in the story.** The collage poster is generated by Flux, and even C-roll "anchors" a real photo by having a model redraw the poster around it. Image-to-video then animates it. For a celebrity investigation that is a fabricated likeness. It breaks the repository's hard rule (CLAUDE.md: "Real, verified photos only for named people/places") and the mission's own rule against fabricated evidence.
2. **Animating a real person's photograph** with a video model could read as a real recording of them. That is unacceptable next to alleged-crime content.
3. **It is cloud-only and paid**, so it would add a new secret and a new per-video cost to an otherwise free pipeline.

## What was done instead (clean-room, no Vox code)

The visual techniques it demonstrates are ideas, not code, and are reimplemented here with licensed, free tools:

| Technique | Our implementation |
|---|---|
| Photographic cut-out sticker | `rembg` (MIT) with the U²-Net model (Apache-2.0), run on the GitHub runner |
| Torn-paper edge and tape | Own Python (Pillow, numpy): dilated alpha plus an irregular edge, procedural paper grain |
| Halftone and archival treatment | Own Python (Pillow, numpy) |
| Layered motion | Remotion compositions per style, driven by the measured narration |
| Music and ducking | Original music synthesised by this repository's own code, mixed under the voice with ffmpeg `sidechaincompress` |
| Real photographs | Wikimedia Commons, licence and author read from the Commons API, recorded in an asset manifest |
